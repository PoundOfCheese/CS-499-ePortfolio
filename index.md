## Professional Self-Assessment
> The various courses and projects of the SNHU Computer Science program have taught me a wide array of skills and exposed me to many different aspects of computer science. Through each course, I have learned my strengths and weaknesses, and I have been able to strengthen both. Each artifact in this portfolio represents a different type of computer science and demonstrates different programming and professional skills I have learned. Projects like the Animal Shelter Database and Full Stack Web App taught me the importance of designing with a team environment in mind. Many projects required writing accessible documentation, which is a skill that I can extend to shareholder communication. Designing each project like a solution to a given problem is a key part of software engineering. Secure programming through following industry standards and implementing security standards like JSON Web Token authentication in my Full Stack Web App all demonstrate my learning regarding security.
>
> Each of the artifacts I chose for this portfolio demonstrate different skills I have learned, as well as different course outcomes for CS 499. The Full Stack Web Application from CS 465 represents the Software Design and Engineering Artifact. It Is the most complex artifact I created in the CS program, and it demonstrates the culmination of my learning up to the capstone. The Intelligent Agent for CS 370 represents the Algorithms and Data Structures Artifact. It showcases complex algorithms that can be used in machine learning, which is an increasingly desirable skill to have in modern computer science. The Python Dashboard and CRUD Module from cs 340 represents the Databases Artifact. It showcases my understanding of databases as well as the thought that goes into designing a system for end users. Each enhancement takes the core teachings of each artifact and builds on them. I also found that each enhancement required more work than I initially thought they would. As I worked on each one, I ran into issues that demanded more attention or found more ways I could elevate the artifact to something representative of professional work. I am grateful for the opportunity to have looked back at each of these artifacts to figure out what I could do better and execute on those improvements.
