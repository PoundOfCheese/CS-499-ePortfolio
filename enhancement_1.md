The artifact I chose for this enhancement is the Full Stack Web Application designed for a travel agency. I created this artifact in August of 2025 as part of the course CS 465 Full Stack Development 1. I chose this artifact for the software engineering and design portion of my ePortfolio because it is a complete application that demonstrates the many different skills and techniques required to create a fully-functional application. The artifact uses the MEAN stack, meaning it has a MongoDB database, an Express website, an Angular single page application, and a Node web server. I also incorporated security by issuing JSON Web Tokens for users of the administrator page. Utilizing each of these components allowed me as a developer to showcase many of the different skills I have learned throughout many different courses in my Computer Science education. When looking at how I could improve the artifact, I thought about the functional design of the application. If I were developing this for a real client, I realized that the application was only partially complete. In the original artifact, only the “travel” page could be modified from the administrator page. The ability for administrators to modify page information without direct access to the server is very valuable and standard for many professional applications, so I decided to expand the functionality of the application to support each of the “rooms”, “meals”, and “news” pages. I learned several things throughout the process of enhancing this artifact. I initially struggled with getting the news page to work with the app’s API. Getting it to work properly with the API required me to rethink how I initially designed the page to read and display data. I also became much more familiar with tools such as Postman and MongoDB Compass since I was making so many more API endpoints and databases. I also learned more about HTML to get the navbar for the SPA to work and display the way I envisioned it. Overall, I now have a better understanding of the MEAN stack and the various components that make it work.
